# 📚 celula-generador-material v0.1.0

## 🌟 ¿Qué es?
Es la factoría de activos de aprendizaje. Utiliza IA para transformar temas densos y documentos técnicos en recursos pedagógicos estructurados (Resúmenes, Cuestionarios, Guías).

## 🚀 Inicio Rápido
### Generación de Material
```bash
python main.py
```

## 📊 Funcionalidades Clave
*   **Generador de Quizzes**: Crea preguntas con opciones y retroalimentación.
*   **Resúmenes Ejecutivos**: Extrae los puntos clave de cualquier texto largo.
*   **Exportación JSON**: Los materiales se guardan de forma estructurada en `/output`.

## 🧠 Filosofía: Eficiencia Pedagógica
Reducir la carga administrativa de crear materiales desde cero permite a los profesores dedicar más tiempo a la interacción directa y de calidad con sus estudiantes.

## 🛠️ Soporte
Consulta los resultados generados en la carpeta `/output`.
