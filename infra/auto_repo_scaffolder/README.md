# 🏗️ auto_repo_scaffolder v0.1.0

## 🌟 ¿Qué es?
Es el arquitecto del ecosistema. Automatiza la creación de nuevos repositorios y módulos siguiendo estrictamente los principios de **Clean Architecture** y la estructura estandarizada de Kenneth Reitz para proyectos Python.

## 🚀 Inicio Rápido
### Instalación
```bash
pip install -e .
```

### Ejecución
```bash
python scaffold.py --name "nueva-celula"
```

## 📊 Funcionalidades Clave
*   **Plantillas Jinja2**: Generación dinámica de `setup.py`, `READMEs` y estructuras de carpetas.
*   **Inyección de Infraestructura**: Asegura que cada nueva célula tenga los archivos `__init__.py` y la estructura de tests necesaria.
*   **Consistencia de Ecosistema**: Garantiza que todos los desarrolladores trabajen sobre el mismo blueprint.

## 🧠 Filosofía: Arquitectura como Código
La calidad del software empieza en la estructura. Este scaffolder elimina el "error humano" en la fase de inicialización, permitiendo que los equipos se enfoquen en la lógica de negocio desde el minuto uno.
