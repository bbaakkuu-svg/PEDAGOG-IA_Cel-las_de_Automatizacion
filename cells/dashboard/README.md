# 📊 celula-dashboard-competencias v0.1.0

## 🌟 ¿Qué es?
Es la ventana visual al éxito educativo. Transforma datos de rendimiento en mapas competenciales multidimensionales, permitiendo una visión 360º del progreso del estudiante.

## 🚀 Inicio Rápido
### Lanzar Dashboard
```bash
python main.py
```
El dashboard se abrirá automáticamente en tu navegador en `http://localhost:8000`.

## 📊 Funcionalidades Clave
*   **Radar Charts Interactivos**: Comparación visual de competencias contra la media del grupo.
*   **IA Insights**: Análisis automático de fortalezas y debilidades.
*   **Estética Premium**: Interfaz moderna basada en "Glassmorphism" con Dark Mode.

## 🧠 Filosofía: Datos con Alma
Los números por sí solos no dicen nada. Este dashboard busca contar la historia de aprendizaje de cada alumno, destacando su potencial único.

## 🛠️ Soporte
Puedes personalizar los datos editando `/data/competencias_alumno.json`.
