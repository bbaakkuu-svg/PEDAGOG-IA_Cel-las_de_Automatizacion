# 🎓 celula-auditor-rubricas v1.0.0 (MVP)

## 🌟 ¿Qué es?
Es un asistente de auditoría pedagógica que utiliza IA para analizar entregas de alumnos en formato PDF y contrastarlas con rúbricas específicas, proporcionando una evaluación justificada y transparente.

## 🚀 Inicio Rápido
### Instalación
```bash
pip install -e .
```

### Ejecución
```bash
python main.py "ruta/a/tu/archivo.pdf"
```

## 📊 Funcionalidades Clave
*   **Extracción PDF**: Motor basado en PyMuPDF para lectura de documentos.
*   **Chain of Thought (CoT)**: La IA justifica cada nota con evidencias textuales del trabajo.
*   **Feedback Formativo**: Genera recomendaciones de mejora personalizadas.

## 🧠 Filosofía: Transparencia Algorítmica
La evaluación debe ser justa y comprensible. Este auditor no solo "da una nota", sino que explica el "porqué", reduciendo la fricción entre el alumno y el sistema de calificación.
