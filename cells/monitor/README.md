# 🕵️ celula-monitor-riesgo v0.1.0

## 🌟 ¿Qué es?
Es el sistema de alerta temprana (Early Warning System) de PEDAGOG-IA. Analiza patrones de comportamiento en los alumnos para detectar proactivamente riesgos de abandono o desmotivación.

## 🚀 Inicio Rápido
### Ejecución del Monitor
```bash
python main.py
```

## 📊 Funcionalidades Clave
*   **Análisis de Logs**: Procesa actividad de login y entregas.
*   **Scoring de Riesgo**: Clasifica a los alumnos (Bajo, Medio, Crítico).
*   **Reportes Visuales**: Genera tablas en consola para una interpretación rápida por parte del tutor.

## 🧠 Filosofía: Cuidado Proactivo
La tecnología debe servir para cuidar a las personas. Este monitor no castiga, sino que alerta al profesor para que pueda intervenir humanamente cuando el alumno más lo necesita.
